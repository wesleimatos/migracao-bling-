# 015 · Exceções: correção de um item sem novo OK; lista de permissões

- **Data:** 02/11/2026 · **Quem:** Weslei
- **Decisão:** correção de UM item pedida pelo PDV ou pela sessão principal (cliente no caixa, barra, preço da etiqueta, regra já aprovada) segue sem novo OK, com backup, conferência e aviso depois. Lote ou decisão nova: só com o OK do Weslei. O .claude/settings.json usa lista de ações liberadas (não o modo plano), para os plantões automáticos não travarem.
- **Por quê:** não deixar cliente esperando nem travar os plantões.
- **Alternativas:** o modo plano do padrão (descartado para este projeto).
