# 006 · Etiqueta divergente: gerar pelo app Etiquetas; roteiro de atendimento

- **Data:** 26/10/2026 · **Quem:** Weslei
- **Decisão:** etiqueta que não passa ou diverge → gerar uma nova pelo app Etiquetas. Roteiro: (1) perguntar se procuraram o produto pelo nome no PDV; (2) etiqueta antiga → reimprimir pelo app; (3) nunca gerar número novo para o produto.
- **Por quê:** as etiquetas antigas saíram do sistema antigo, e boa parte dos erros vinha de colaboradores usando o caminho antigo, e não do cadastro.
- **Alternativas:** não registradas.
