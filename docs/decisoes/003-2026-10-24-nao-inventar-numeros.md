# 003 · Não inventar e não corrigir números

- **Data:** 24/10/2026 · **Quem:** Weslei
- **Decisão:** só usar o que já existe. A única decisão é onde o código fica: barra no padrão EAN vai para o campo EAN, fora do padrão vai para o SKU. Números fora do padrão (dígito verificador errado, dígito faltando) não são corrigidos.
- **Por quê:** os números estão impressos nas embalagens e etiquetas.
- **Alternativas:** não registradas.
